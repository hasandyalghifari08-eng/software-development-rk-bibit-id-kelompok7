# RK BIBIT ID - Website Katalog Digital Bibit Tanaman

Proyek mata kuliah Software Development (TIF2001), Kelompok 7.

## Deskripsi
Website katalog digital bibit tanaman yang menampilkan jenis bibit, harga, dan ketersediaan stok dalam satu tempat. Pemesanan dilakukan lewat tombol yang mengarahkan pembeli ke WhatsApp, Shopee, atau TikTok Shop. Pemilik toko mengelola data melalui halaman admin.

## Struktur Folder
- docs/ : proposal, diagram, ERD, dan mockup
- database/ : skema SQL
- public/ : halaman pengunjung
- admin/ : halaman admin
- uploads/ : gambar bibit (tidak ikut di-push)

## Alur Kerja Git
Setiap anggota bekerja di branch masing-masing (feature-nama), lalu membuat Pull Request ke main. Pull Request di-merge oleh anggota lain, bukan oleh pembuatnya.
